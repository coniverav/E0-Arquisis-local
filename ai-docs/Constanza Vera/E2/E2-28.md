## Declaración de uso de IA — E2-028

Para el desarrollo de la tarjeta **E2-028: Crear oferta seller al abrir mercado**, se utilizó ChatGPT como herramienta de apoyo mediante consultas por chat.

La herramienta se utilizó para comprender el proceso de creación de ofertas de energía, determinar cuándo deben publicarse, calcular la cantidad disponible a partir de Wallet y evitar la creación de ofertas duplicadas para una misma ciudad y ciclo.

ChatGPT proporcionó explicaciones, propuestas de código y sugerencias de pruebas para implementar la funcionalidad, las cuales fueron revisadas e integradas al proyecto.

### Prompts relevantes utilizados

1. "¿Cómo funciona la creación de ofertas de energía en el mercado?"
2. "¿Cómo puedo crear automáticamente una oferta al abrir el mercado?"
3. "¿Cómo calculo la cantidad de energía disponible para vender?"
4. "¿Cómo evito crear dos ofertas para una misma ciudad y ciclo?"
5. "¿Me ayudas a crear tests para verificar que la oferta se genere correctamente?"
