## Declaración de uso de IA — E2-033

Para el desarrollo de la tarjeta **E2-033: Responder bid-accepted solo tras swap-proposed**, se utilizó ChatGPT como herramienta de apoyo mediante consultas por chat.

La herramienta se utilizó para comprender el flujo de confirmación de swaps, validar la información recibida desde Wallet, generar mensajes `bid-accepted`, manejar la idempotencia y desarrollar pruebas para verificar el funcionamiento.

ChatGPT proporcionó propuestas de código, scripts y tests, los cuales fueron revisados e integrados al proyecto.

### Prompts de ejemplo asociados al desarrollo

1. "¿Cómo sé cuándo Wallet confirmó que se propuso un swap?"
2. "¿Qué información debe incluir el mensaje bid-accepted?"
3. "¿Cómo verifico que el swap corresponda al bid original?"
4. "¿Cómo evito enviar dos veces el mismo bid-accepted?"
5. "¿Me ayudas a hacer tests para comprobar que bid-accepted se envíe correctamente?"
