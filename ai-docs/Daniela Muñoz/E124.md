## Declaración de uso de IA — E1-24

Para el desarrollo de la tarjeta E1-24 se utilizó ChatGPT como herramienta de apoyo mediante consultas por chat.

La herramienta se utilizó principalmente para:

- Revisar la estructura existente de persistencia y su relación con AD2.
- Guiar la incorporación de Alembic para manejar migraciones versionadas de PostgreSQL.
- Proponer la separación de las migraciones entre el esquema base proveniente de E0 y las entidades incorporadas para E1.
- Apoyar la configuración de `alembic.ini`, `env.py`, Dockerfile y Docker Compose.
- Analizar errores encontrados durante la generación y ejecución de migraciones, incluyendo dependencias de SQLModel y problemas de ejecución dentro de contenedores.
- Proponer comandos de validación para comprobar la creación del esquema desde cero, la aplicación de migraciones y la persistencia de datos después de reiniciar PostgreSQL.
- Revisar los resultados de las pruebas antes de considerar finalizada la implementación.

ChatGPT no tuvo acceso directo al repositorio ni realizó modificaciones autónomas sobre el codebase. Las propuestas de código y comandos fueron revisadas, copiadas y ejecutadas manualmente, verificando sus resultados antes de incorporarlas al proyecto.

La implementación final fue validada mediante Alembic, PostgreSQL, Docker Compose y pruebas de persistencia después de reinicios.
